# Changelog

All notable changes are documented here. The project follows semantic-style version labels but has not published formal releases.

## Unreleased

- Added reproducible `pipeline` quick, verification, and explicit full-training modes.
- Added model registry, monitoring, drift indicators, and transparent persistence fallback.
- Added versioned model, metrics, provenance, monitoring, and frozen-forecast API endpoints.
- Added reviewer-facing forecasting dashboard, data/model cards, research report, reproducibility guide, portfolio notes, and ethical-use guidance.
- Added 30 focused tests, Ruff, pre-commit, GitHub Actions CI, Docker, Compose, and Streamlit deployment configuration.

## 2.0.0 — research artifact schema

- Added leakage-safe seven-day change target and chronological evaluation framework.
- Compared 11 baseline, statistical, linear, boosted, hybrid, and ensemble candidates.
- Promoted a development-selected validation-weighted ensemble and preserved holdout artifacts.
- Added prediction intervals, provenance, leakage audit, model registry, error regimes, and standalone HTML report.
